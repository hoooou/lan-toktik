# lan-toktik

本地局域网**抖音式短视频流**播放器 —— 在手机浏览器上以竖屏滑动流，观看电脑上的本地视频。

手机与电脑连接同一 Wi-Fi，无需拷贝任何文件，打开网页即享抖音式刷视频体验。

## ✨ 特性

- **抖音式竖屏视频流**：上下滑动无缝切换
- **单击播放/暂停**，长按 **2 倍速**
- **真实点赞**：刷新页面后状态保持
- **收藏 + 底部三 Tab（全部 / 收藏 / 已删除）**
- **回收站**：删除视频立即移入回收站，可还原或永久清空
- **横屏视频一键旋转**：画面旋转铺满、侧边栏自动隐藏、进度条跟随画面
- **沉浸式全屏**：隐藏浏览器地址栏/状态栏
- **零依赖**：Node 仅做静态文件服务，前端为单文件 HTML
- **局域网直连**：`http://<电脑IP>:8080` 即用

## 🚀 快速开始

**前置条件**：需要 `ffmpeg` / `ffprobe`（必需，用于媒体元数据扫描与封面抽帧；macOS: `brew install ffmpeg`）

```bash
# 1. 把视频放进 media/ 目录（支持 mp4 / webm / mov 等）
# 2. 启动服务（首次启动会后台自动扫描媒体元数据与封面）
npm start
# 或 node server.js

# 3. 手机连接同一 Wi-Fi，浏览器打开：
#    http://<电脑IP>:8080
```

> 提示：视频也可以使用软链接放入 `media/`，无需复制大文件。

## 🔌 接口

| 接口 | 说明 |
| --- | --- |
| `POST /api/events` | 行为事件批量上报（点赞/收藏/观看等），更新推荐画像 |
| `GET /api/recommend` | 推荐列表（按画像打分排序，含理由、副本分组、封面标记） |
| `GET /data/covers/<name>` | 封面图静态服务 |

## 🎮 操作说明

| 操作 | 功能 |
| --- | --- |
| 上下滑动 | 切换视频 |
| 单击画面 | 播放 / 暂停 |
| 长按画面 | 2 倍速播放 |
| 双击画面 | 快速播放 / 暂停 |
| 底部 Tab 栏 | 切换「全部 / 收藏 / 已删除」视图 |
| 右侧 ♥ 点赞 | 标记喜欢（刷新后保留） |
| 右侧 🗑 删除 | 立即移入回收站（可在「已删除」Tab 还原） |
| 右侧 ⭐ 收藏 | 标记收藏（刷新后保留） |
| 收藏 Tab 侧边栏「取消收藏」 | 从收藏视图移除 |
| 已删除 Tab「还原」 | 移回媒体库 |
| 已删除 Tab「删除全部」 | 永久清空回收站（需确认） |
| 横屏视频「旋转」按钮 | 画面旋转 90° 铺满观看 |
| 控制栏「全屏」按钮 | 沉浸式全屏 |
| 进度条 | 拖动 / 点击跳转（旋转时跟随画面） |

## 📁 项目结构

```
lan-toktik/
├── index.html    # 前端全部逻辑与样式（单文件、零依赖）
├── server.js     # 静态文件服务（支持 Range 流、回收站接口）
├── media/        # 视频目录（放入你的视频）
├── .trash/       # 回收站目录（删除的视频移到这里，可还原）
└── package.json
```

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建步骤、零运行时依赖）
- Node.js 内置 `http` 模块（支持 Range 请求，大视频拖动流畅）
